# Food photography

These eight illustrative food images were created with the built-in Image Generation tool for this project. They are bundled locally; generating a recipe does not call an image API. They show food inspiration, not a verified photograph of an individual generated recipe.

Files: `chickpea.jpg`, `burger.jpg`, `pasta.jpg`, `salad.jpg`, `ramen.jpg`, `curry.jpg`, `tacos.jpg`, `paella.jpg`.

Exact generation prompts and provenance are recorded in `prompts.json`. The original generated PNGs were converted to 1200-pixel-wide JPEGs for faster loading. No stock photography or external image hotlinks are used.
